See what's using your disk.

DiskScope is a fast, native macOS disk-usage browser — the power of ncdu with the Finder interface you already know. Pick any drive or folder and drill straight to what's taking up space.

Everything you need to reclaim space

Like ncdu or du, but you browse the results the way you browse your Mac.

Pick any drive or folder

The sidebar lists every mounted drive — internal, external, USB and network — with used and free space, plus your favorite folders. Click one to scan it, eject drives in place, or drop any folder on the window.

Finder-style browsing

Column, list and sunburst views with sizes and usage bars, back/forward history, a clickable path bar, and the keyboard shortcuts you expect (⌘[ ⌘] ⌘↑ ⌘2 ⌘3 ⌘4).

Fast, parallel scanner

A multi-threaded scanner walks the disk on several cores — about 3× faster than a single-threaded walk on a 3-million-item folder — with live progress you can cancel at any time.

Search the whole scan

Type a name to search everything that was scanned (or just the current folder). Matches are listed largest first, so the big offenders surface immediately.

Disk usage vs. file size

Switch between space actually allocated on disk and the apparent (logical) size — the difference reveals compressed, sparse and tiny files. Sort by size, name, item count or date.

Clean up with confidence

Move items to the Trash, show them in Finder, copy their paths or export the list as CSV. Rescan just the folder you're in after changes — totals update all the way up.

New in 1.1

See a whole disk at a glance, find out where the “missing” space went, track down duplicate files, and ask Claude about your scan.

Sunburst view · ⌘4

Your disk as rings

A third view next to List and Columns. The folder you're in sits in the center; each ring is one level deeper, and every slice is sized by the space it uses — so the biggest things are impossible to miss.

  • Hover a slice for its name, size and share of the folder.
  • Click a slice to drill in; click the center to go back up.
  • A “Largest items” legend sits alongside, and tiny items are grouped so the chart stays readable.
Not in scan

Where did the rest of my space go?

Finder says the disk is nearly full, but the files add up to far less. When you scan a whole disk, DiskScope now shows that gap — and what's in it.

  • Other volumes that share the disk: virtual-memory swap, Preboot, Recovery, Software Update.
  • Time Machine local snapshots, folders DiskScope wasn't allowed to read, and hidden system data.
  • How much is purgeable — space macOS frees by itself when it needs to.
  • Shown in the status bar, and as a gray slice in the sunburst.
Find Duplicates

Find copies, compare them side by side

Pick a folder — and, if you like, a second folder to compare it with, such as a backup drive. DiskScope matches files by size, then by SHA-256 checksum, and lists the duplicate sets with the biggest savings first.

  • See two copies next to each other: text, images, video and audio (with Play Both), PDFs, or a Quick Look thumbnail.
  • Mark each copy Keep or Remove, or use a rule: keep the copy in Folder A or B, the oldest, the newest, or the shortest path. Every set always keeps at least one copy.
  • iCloud and Dropbox placeholders are skipped, so nothing gets downloaded. Hard links aren't counted as duplicates.

A removal script you review

Find Duplicates never deletes or moves anything itself. Removal Script… saves a bash script you can read first, then run in Terminal: bash remove-duplicates.sh is a dry run, and adding --apply moves the marked copies to the Trash. Before each move it re-checks with shasum -a 256 that the file and the copy you're keeping are still identical, and skips anything that changed. The script is saved without execute permission.

Export to CSV

Export the folder you're viewing or the whole scan — path, kind, size on disk, apparent size, items, modified — or the duplicate sets with their checksums, sizes, wasted space and Keep/Remove marks. Values a spreadsheet could treat as formulas are neutralised, so opening an export can't run anything.

Ask Claude · optional

Ask questions about your scan

Open the Ask Claude panel from the toolbar and ask things like “What's using the most space?” or “What can I safely delete?”. Claude answers from a summary of your scan.

  • Off until you turn it on and add your own Anthropic API key in DiskScope › Settings. The key is kept in your Mac's Keychain, and usage is billed to your key.
  • Getting a key: sign in to the Claude Console, add credit under Billing, then create a key under API Keys and paste it into Settings. The API is billed separately from a Claude.ai subscription; a typical question costs a few cents (pricing).
  • Sends a text summary — names, sizes, dates — never file contents. “What gets sent” shows you exactly what will be sent before you press Send.
  • Claude can only answer. It can't open, move or delete anything.

Numbers you can trust

DiskScope reads sizes straight from the file system, the same way du does — and its totals match du exactly.

  • Metadata onlyEach folder is listed with readdir and every entry is measured with fstatat. Scanning never opens or reads files.
  • Symlinks are never followedA link counts as the link itself, so nothing is counted twice and scans can't wander off into other places.
  • Hard links counted onceFiles with several names share one inode; DiskScope counts that storage a single time, like du.
  • No double counting on the startup diskWhen scanning /, the system's duplicate view of your data volume, Software Update's second mount of the system volume, and other mounted disks are skipped.
  • The gap is accounted forFor whole-disk scans, the disk's used space is compared with what the scan found, and the difference is broken down using the file system's own per-volume figures.

Private by design. Careful with your files.

DiskScope works offline by default. The only network feature is the optional Ask Claude panel, and it sends nothing until you turn it on and press Send. Nothing is tracked, and scanning never changes anything on disk.

  • Read-only scanningScans read only file metadata: names, sizes and dates. The only thing in DiskScope that changes files is Move to Trash in the browser, and only when you confirm it.
  • File contents only when you askFind Duplicates reads files to compute their SHA-256 checksums, and its previews read the copies you compare, all on your Mac. Only regular files are opened, and iCloud or Dropbox placeholders are skipped so nothing is downloaded. Previews use Apple's own frameworks (ImageIO, AVFoundation, PDFKit, Quick Look), the same ones Finder uses.
  • Ask Claude: opt-in, and you see what's sentIt uses your own Anthropic API key, kept in the macOS Keychain. When you press Send, a text summary of the scan goes to Anthropic's API over HTTPS: names relative to the scan root (your home folder shown as ~), sizes, dates and the “Not in scan” breakdown. Never file contents. “What gets sent” shows it all before you send, and Claude can't open, move or delete anything.
  • Duplicates: you decide, you run itFind Duplicates never deletes anything. Its removal script is a dry run unless you add --apply, always keeps at least one copy, and re-checks each file's checksum right before moving it to the Trash.
  • Protected locationsSystem folders, top-level folders like your home, Library and Applications, and whole drives can't be sent to the Trash.
  • Re-checked before every moveRight before trashing, each item is verified to still be the same kind of item at the same real location — if anything changed since the scan, DiskScope refuses.
  • Clear confirmationThe prompt lists full paths, with invisible or direction-reversing characters made visible so a file name can't disguise itself. Items go to the Trash, so you can still put them back.
  • Spreadsheet-safe exportsCSV exports neutralise values a spreadsheet could treat as formulas.
  • Hardened RuntimeBuilt with Apple's Hardened Runtime and no special entitlements.

Download & install

Download the DMG, open it, and drag DiskScope to Applications.

Download for Mac

macOS 14 Sonoma or later · universal (Apple silicon & Intel) · free & open source (MIT). Each release lists the DMG's SHA-256 so you can check your download.

First launch: DiskScope isn't notarized by Apple yet (that needs a paid Developer ID), so macOS says it can't verify the developer. Open System Settings › Privacy & Security, scroll down and click Open Anyway. On macOS 15 and later, right-click › Open no longer does this.

Or build it from source

# Build a universal app and install it in /Applications
git clone https://github.com/steveo-ocheng/DiskScope.git
cd DiskScope
./build-app.sh --install
Building needs only Apple's free Command Line Tools — no Xcode project. Install them with xcode-select --install if you don't have them.
Optional — complete results: macOS keeps some folders (like Mail and Messages) private. To include them, add DiskScope under System Settings › Privacy & Security › Full Disk Access, then rescan. The orange “unreadable” note in DiskScope's status bar opens that page for you.
