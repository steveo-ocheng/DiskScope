See what's using your disk.

DiskScope is a fast, native macOS disk-usage browser — the power of ncdu with the Finder interface you already know. Pick any drive or folder and drill straight to what's taking up space.

Free · macOS 14 Sonoma or later · Apple silicon & Intel

Everything you need to reclaim space

Like ncdu or du, but you browse the results the way you browse your Mac.

Pick any drive or folder

The sidebar lists every mounted drive — internal, external, USB and network — with used and free space, plus your favorite folders. Click one to scan it, eject drives in place, or drop any folder on the window.

Finder-style browsing

Column and list views with sizes and usage bars on every row, back/forward history, a clickable path bar, and the keyboard shortcuts you expect (⌘[ ⌘] ⌘↑ ⌘2 ⌘3).

Fast, parallel scanner

A multi-threaded scanner walks the disk on several cores — about 3× faster than a single-threaded walk on a 3-million-item folder — with live progress you can cancel at any time.

Search the whole scan

Type a name to search everything that was scanned (or just the current folder). Matches are listed largest first, so the big offenders surface immediately.

Disk usage vs. file size

Switch between space actually allocated on disk and the apparent (logical) size — the difference reveals compressed, sparse and tiny files. Sort by size, name, item count or date.

Clean up with confidence

Move items to the Trash, show them in Finder or copy their paths. Rescan just the folder you're in after changes — totals update all the way up.

Numbers you can trust

DiskScope reads sizes straight from the file system, the same way du does — and its totals match du exactly.

  • Metadata onlyEach folder is listed with readdir and every entry is measured with fstatat. Files are never opened or read.
  • Symlinks are never followedA link counts as the link itself, so nothing is counted twice and scans can't wander off into other places.
  • Hard links counted onceFiles with several names share one inode; DiskScope counts that storage a single time, like du.
  • No double counting on the startup diskWhen scanning /, the system's duplicate view of your data volume and other mounted disks are skipped.

Private by design. Careful with your files.

DiskScope has no network code at all. Nothing is uploaded, nothing is tracked, and scanning never changes anything on disk.

  • Read-only scanningScans only read file metadata. The only thing that changes files is Move to Trash — and only when you confirm it.
  • Protected locationsSystem folders, top-level folders like your home, Library and Applications, and whole drives can't be sent to the Trash.
  • Re-checked before every moveRight before trashing, each item is verified to still be the same kind of item at the same real location — if anything changed since the scan, DiskScope refuses.
  • Clear confirmationThe prompt lists full paths, with invisible or direction-reversing characters made visible so a file name can't disguise itself. Items go to the Trash, so you can still put them back.
  • Hardened RuntimeBuilt with Apple's Hardened Runtime and no special entitlements.

Build & install

There's no notarized download yet, so for now DiskScope is built from source. It takes a minute and needs only Apple's free Command Line Tools — no Xcode project.

Requirements: macOS 14 Sonoma or later, on Apple silicon or Intel. Install the tools with xcode-select --install if you don't have them.
# Build a universal app and install it in /Applications
git clone https://github.com/steveo-ocheng/DiskScope.git
cd DiskScope
./build-app.sh --install
Optional — complete results: macOS keeps some folders (like Mail and Messages) private. To include them, add DiskScope under System Settings › Privacy & Security › Full Disk Access, then rescan. The orange “unreadable” note in DiskScope's status bar opens that page for you.
